本模块为顶层可执行入口，不含业务包，仅按用途分为两类：
- `scripts/`：独立可运行的 Python 脚本，通过 `argparse` 暴露 CLI 参数，直接依赖 torch/torchvision/sklearn 完成端到端流程。
  - `train_classifier.py`：基于 torchvision `ImageFolder` + ResNet18 ImageNet 预训练权重做二分类微调，数据路径硬编码到仓库根 `datasets/ArchaeoMind_dataset/{train,val,test}`，模型以 `best_model.pth` 落盘；优化器仅更新 FC 层（`model.fc.parameters()`），训练/验证/测试三段循环分别由 `train_one_epoch` 与 `evaluate` 封装。
  - `test_baidu_ocr.py`：通过 `requests` 调用 Baidu AI Cloud REST API，凭据从环境变量 `BAIDU_OCR_API_KEY` / `BAIDU_OCR_SECRET_KEY` 读取，封装 general_basic/general_enhanced/table/accurate 等若干 OCR 子函数供 notebook 复用。
- `notebooks/`：Jupyter Notebook 与 Markdown 调研报告，`dataset-research.md` 汇总 COCO/Roboflow Universe/ImageNet 三类数据集的规模、类别映射、下载方式与适用性评估，作为后续模型选型依据；`.ipynb_checkpoints/` 为 Jupyter 自动保存的中间态。
