- CLI 脚本统一使用 `argparse` 声明可选超参并通过 `if __name__ == "__main__": main()` 入口启动。
- 外部凭据一律通过 `os.environ[...]` 读取，避免在源码中硬编码密钥。
- HTTP 请求统一采用 `requests.post(...).raise_for_status()` 模式，失败时抛出异常而非静默返回。
- GPU/CPU 设备选择遵循 `torch.device("cuda" if torch.cuda.is_available() else "cpu")` 并在打印后显式 `.to(device)` 移动张量。
