# 📊 计数特征提取器

**考古简报智能分析工具**

专业的考古简报计数特征提取与分析平台，采用两阶段提取技术，自动识别和提取墓葬中的器物数量、尺寸、重量等信息。

---

## ✨ 功能特点

### 🔍 两阶段智能提取

**阶段一：模式发现**
- 自动扫描全文
- 识别所有计数模式（器物数量、尺寸、重量等）
- 统计模式频率和分布

**阶段二：精确提取**
- 基于发现的模式进行精确提取
- 按墓葬组织数据
- 生成结构化报告

### 📊 支持的计数类型

| 类型 | 示例 | 说明 |
|------|------|------|
| 器物数量 | "共9件"、"出土陶罐3件" | 器物总数统计 |
| 器物编号 | "M1:2"、"M1：12号" | 具体器物标识 |
| 尺寸量化 | "口径34.9厘米" | 器物尺寸信息 |
| 重量 | "重178.5克" | 重量数据 |
| 范围值 | "6.3-6.7厘米" | 数值范围 |
| 墓葬尺寸 | "墓口长2.50米" | 墓葬结构尺寸 |

### 🏺 自动识别

- **器物类别**: 铜器、陶器、玉器、铁器、金银器、骨器、石器、漆木器
- **墓葬结构**: 土坑竖穴墓、砖室墓、木椁墓、洞室墓等
- **特殊特征**: 盗洞、陪葬、封土、二层台等

## 🚀 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动应用

```bash
# 方式一：使用启动脚本（推荐）
./启动.sh

# 方式二：直接运行
streamlit run app.py
```

应用将在浏览器中自动打开（默认地址：http://localhost:8501）

## 📖 使用方法

### 1. 输入数据

支持三种输入方式：
- **上传文件**: 支持 .md 和 .txt 格式
- **粘贴文本**: 直接粘贴考古简报内容
- **使用示例**: 选择系统提供的示例文件

### 2. 查看分析结果

- **总览指标**: 墓葬数量、器物总数、发现模式数、器物类型数
- **模式发现**: 查看识别到的计数模式和频率
- **器物提取**: 查看按墓葬组织的器物信息

### 3. 导出数据

支持三种导出格式：
- **JSON 报告**: 完整的结构化数据
- **CSV 明细**: 器物详细信息表格
- **CSV 统计**: 模式统计信息
