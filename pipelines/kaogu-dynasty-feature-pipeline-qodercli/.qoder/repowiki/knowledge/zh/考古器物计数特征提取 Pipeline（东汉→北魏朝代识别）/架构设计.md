本模块由数据层与 Notebook 实现层组成：
- `data/` 为只读输入目录，存放经 PaddleOCR-VL-1.6 从 PDF 转出的 `.md` 文本，按主题子目录（京津冀、图像与装饰等）组织，包含《光宅中原》《幽燕地区两汉墓葬研究》《山东地区汉代墓葬的考古学研究》等多篇考古论文。
- `dynasty_feature_pipeline.ipynb` 是单文件端到端 Notebook，按四层架构自顶向下编排：Layer 1 用 `pandas.read_html` + `BeautifulSoup` 解析表格、按朝代关键词（`DYNASTY_KEYWORDS`、`REGION_KEYWORDS`）做语义分块，输出 `Chunk` dataclass；Layer 2 通过统一 `call_llm` 接口（支持 OpenAI / Anthropic 双后端，由 `LLM_BACKEND` 切换）执行阶段 A（无预设 schema 的特征发现 prompt）与阶段 B（结构化 JSON 提取）；Layer 3 用 pandas 聚合特征频次并计划做卡方/信息增益分析；Layer 4 定义交叉验证迭代流程。
- 依赖方向单向：Markdown → Chunk → LLM 调用 → 特征词典 DataFrame，无外部包导入到 Notebook 之外的反向依赖。
